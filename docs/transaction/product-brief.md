# LoadBond transaction milestone

## Customer decision

Developer treasury, supported by counsel, needs to reconcile the security posted for one economic project with the current operative evidence. The initial question is: **what remains exposed after a project decision, and what evidence is missing before treasury can pursue a change?** This is a customer hypothesis, not a validated market finding.

The research's wider ambition remains a source-backed contractual-state engine. Cross-site restructuring requires its own occurrence, legal, bank-economic, and beneficiary-protection gates. A synthetic release case does not pass those gates.

## Delivered transaction

Riverbend is an authored, pre-reviewed synthetic fixture: 300 MW, Alder and Birch sites, $12M and $18M independent instrument faces. Alder's $2M engineering obligation, Birch's $3M engineering obligation, and Birch's conditional $15M construction obligation remain separately modeled. Birch's two components share one instrument; its face is counted once.

1. Both sites are candidates. Compute $30M modeled instrument exposure and $20M maximum underlying obligations.
2. An explicit demonstration review records Birch selected and Alder abandoned. Commercial status changes; instrument exposure remains $30M.
3. Attach the synthetic beneficiary release. No automatic approval occurs. Old assessments become historical; unfinished document review prevents a complete new assessment.
4. Review the exact release quotation with a named local reviewer and a written reason. Instrument import/update and input review use existing separate endpoints. The assessment becomes $18M instrument exposure; obligations remain $20M.
5. Test evidence withdrawal with another explicit decision. Restore the instrument to effective status, remove release support, and reconfirm its original face. Exposure returns to $30M. The earlier $18M snapshot remains reproducible and exportable.

The walkthrough provides selectable instrument contributions, exact quotations, document versions, source navigation, fixture-author and operator review history, next-decision guidance, and assessment history. It calls the existing solver and saves real local records and immutable assessments. It does not use prerecorded calculations or imply AI extraction.

## What this demonstrates

Evidence affects a financial result through an explicit review boundary. Site abandonment supplies no release credit. An instrument release does not erase its underlying obligations. Missing bank/cash metrics remain unknown. An amended release invalidates current inputs while historical snapshots remain reproducible.

## What remains unbuilt or unproven

- General transaction-event ingestion and daily historical reconstruction.
- Automated reconciliation of arbitrary operative clauses and draw-trigger states.
- General opportunity detection and an approval-owner action queue.
- Real customer evidence, willingness to pay, legal feasibility, or bank capacity/cash benefit.
- Reliable extraction quality: the earlier 12-document evaluation still missed its precision gate. Local extraction remains experimental.

The restored workbench is the default interface. The abandoned redesign source is retained but does not serve `/`. No paid services, public deployment, confidential uploads, or outreach were enabled.

## Next product test

Reconstruct one evidence-complete transaction from dated instruments, agreements, amendments, notices, releases, and utilization records. Define the treasury decision before expanding features. Test whether a reviewer can identify the same unresolved security position and supporting evidence using LoadBond, with less reconstruction work than their existing process. Do not label a missing release as a legally releasable instrument or equate face reduction with money saved.
